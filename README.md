Mundo Running Full es una empresa dedicada a brindar soluciones integrales para deportistas y entusiastas del movimiento. Ofrecemos una amplia variedad de productos de running, ciclismo y natación, seleccionados para cubrir las necesidades tanto de aficionados como de atletas avanzados.

Contamos con un servicio técnico especializado en bicicletas, orientado al mantenimiento, reparación y optimización de todo tipo de modelos. Además, participamos activamente en eventos deportivos mediante servicios de fotografía profesional, y organizamos carreras y actividades recreativas enfocadas en la comunidad deportiva.

Este proyecto tiene como objetivo desarrollar la plataforma web oficial de Mundo Running Full, donde los usuarios podrán conocer sus servicios, explorar el catálogo de productos y mantenerse informados sobre próximos eventos.


## 🚀 Instalación y uso local del código
- Cloná el repositorio: `git clone https://github.com/CeciliaBPerdomo/mundo_running_a_full` 
- Ingresá al directorio del proyecto: `cd mundorunning`
- 📍 **Front End**
    - Instalá las dependencias: `npm install`
    - Levantá el servidor de desarrollo: `npm run dev`
    - Abrí tu navegador en: `http://localhost:5173`
- 📍**Back End**
    - Ingresá al directorio `backend`
    - Levantá el servidor de desarrollo: `tsc --watch` y `nodemon ./dist/index.js`
